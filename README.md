# Todo App

HTML, CSS, JavaScript만으로 구현한 간단한 Todo(할 일 관리) 웹 앱입니다.
별도의 서버나 빌드 과정 없이, 브라우저에서 `index.html`을 열면 바로 사용할 수 있습니다.

## 사용 기술

- **HTML5**: 앱의 기본 구조 (`index.html`)
- **CSS3**: 레이아웃 및 스타일링 (`style.css`) — 별도 프레임워크 없이 순수 CSS로 작성
- **Vanilla JavaScript (ES6+)**: 할 일 추가/수정/삭제, 필터링 등 동작 로직 (`script.js`) — 외부 라이브러리 없음
- **Web Storage API (`localStorage`)**: 브라우저에 할 일 목록을 저장하여 새로고침하거나 다시 방문해도 데이터가 유지됨

## 실행 방법

빌드나 설치 과정이 필요 없습니다. `index.html` 파일을 더블클릭하거나 브라우저에서 직접 열면 됩니다.

```
open index.html         # macOS
xdg-open index.html     # Linux
```

## 사용자 매뉴얼 (간편 사용법)

1. **할 일 추가하기**
   화면 상단 입력창에 할 일 내용을 입력하고 `추가` 버튼을 누르거나 `Enter`를 치면 목록에 추가됩니다.

2. **할 일 완료 처리하기**
   각 항목 왼쪽의 체크박스를 클릭하면 완료 상태로 표시되며, 텍스트에 취소선이 그어집니다. 다시 클릭하면 완료가 취소됩니다.

3. **할 일 내용 수정하기**
   항목의 텍스트 부분을 더블클릭하면 수정 모드로 전환됩니다. 내용을 변경한 뒤 `Enter`를 누르거나 다른 곳을 클릭하면 저장되고, `Esc`를 누르면 수정이 취소됩니다.

4. **할 일 삭제하기**
   각 항목 오른쪽의 `✕` 버튼을 누르면 해당 항목이 목록에서 삭제됩니다.

5. **목록 필터링하기**
   화면 중간의 `전체` / `진행 중` / `완료` 버튼으로 원하는 상태의 할 일만 모아서 볼 수 있습니다.

6. **완료된 항목 한 번에 삭제하기**
   화면 하단의 `완료 항목 삭제` 버튼을 누르면 완료 표시된 모든 할 일이 한 번에 삭제됩니다.

7. **남은 할 일 개수 확인하기**
   화면 하단 왼쪽에 아직 완료되지 않은 할 일의 개수가 표시됩니다.

> 입력한 할 일 목록은 브라우저의 `localStorage`에 저장되므로, 같은 브라우저에서 페이지를 새로고침하거나 다시 방문해도 목록이 그대로 유지됩니다. (단, 브라우저 저장소를 지우거나 다른 브라우저/기기로 접속하면 목록은 공유되지 않습니다.)
